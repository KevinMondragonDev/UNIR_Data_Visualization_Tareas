# 📊 UNIR · Visualización de Datos — Tareas

Repositorio donde llevo todas las tareas de visualización de datos del programa de **Maestría en Big Data (UNIR)**.

Cada tarea vive en su propia carpeta numerada, con sus archivos y, si hace falta, sus datos y notas.

|---|---|---|---|

## 📁 Convención

- Carpetas: `NN_tarea_NN_tema_en_snake_case/` (por ejemplo `02_tarea_02_tableau/`).
- Cada carpeta de tarea incluye un `README.md` corto con el enunciado, cómo abrirla o ejecutarla y las conclusiones.
- Los datos van en una subcarpeta `datos/` dentro de la tarea.

## 🚀 Cómo abrir una tarea

Las tareas en HTML se abren directamente en el navegador:

```bash
start 01_tarea_01_google_charts/first-test.html
```

Para trabajar con Python, Node y Angular uso la imagen Docker `devenv` (ver `UNIR_Python_Certification` para las convenciones de código).
